# AI Drop Hunter (ai-hub-claude_ai)

Локальний український вебзастосунок для дослідження криптопроєктів, оцінки умов та обліку завдань. Усі мережі на рівних; AI Jobs не входять до runtime.

> **Про цю папку.** Це окрема, свідомо незалежна реалізація всередині монорепо `ai-hub` — не заміна й не форк наявних `agents/drop-hunter/`, `agents/multi-chain/` чи `apps/web/`. Код і 43 тести перенесено без змін із самостійного репозиторію `viktoriankv02/ai-drop-hunter` (SQLite, нуль npm-залежностей у рантаймі) як основа для подальшого розвитку в бік моделі `Opportunity → Project → Task → Agent → Action → Chain → Execution → Evidence → Reward`. Інтеграція з ончейн-контрактами `ai-hub` (ActivityRegistry/AIAgentEngine) — свідомо відкладена на пізніший окремий крок; поки що весь стан — локальна SQLite, без ончейн-запису.

## Запуск

Node.js 24+. Для запуску й основних тестів зовнішніх npm-залежностей немає.

```powershell
cd D:\Projects\ai-drop-hunter
npm test
npm start
```

Відкрийте http://127.0.0.1:4317. Зупинка: Ctrl+C. Дані — у `data/drop-hunter.sqlite`, поза Git. Для резервної копії зупиніть сервер та скопіюйте всю папку `data`.

## Що означають оцінки

Бали описують повноту та придатність плану участі за оцінкою користувача, не ймовірність дропу. Ваги: відповідність умовам 30%, зрозумілість винагороди 25%, підтверджуваність виконання 20%, відомі витрати 15%, відповідність строкам 10%. Невідомі сигнали не додають балів; їхню частку показано окремо. Високі бали не скасовують високий ризик або минулий дедлайн.

Підтвердження джерела не підтверджує винагороду. Статус «оголошено» — висновок користувача із записаним доказом. Завдання виконуються вручну; застосунок зберігає повідомлення про виконання, без незалежного on-chain підтвердження.

## Обмеження

Це однокористувацька локальна версія. Токен запобігає змінам зі сторонніх вебсторінок, але не замінює авторизацію. Не публікуйте цей сервер через reverse proxy.

Каталог Ink apps потребує JavaScript: статичний адаптер чесно повертає помилку недостатнього тексту. Автоотримання працює лише для фіксованого списку офіційних URL; користувацькі URL сервер не завантажує.

LLM-провайдер, автоматичні check-in, підключення гаманця, симуляції та виконання транзакцій ще не реалізовані. Приватні ключі не потрібні. Інші мережі поки є категоріями дослідження.

## Перевірки

`npm test`: 32 unit/integration тести, включно зі збереженням після перезапуску, зміною джерел, часовими поясами, HTTP, повторюваністю та конфліктами розкладу.

`npm run test:browser`: повний сценарій у headless Edge, desktop/mobile, без змін робочої БД. Потребує встановленого Edge та пакета Playwright. Якщо Playwright розташований поза проєктом, задайте `PLAYWRIGHT_MODULE` як абсолютний шлях до пакета. Знімки зберігаються в `data/qa` і не комітяться.

## Оновлення 0.4: фактичні результати

Ручний журнал винагород і витрат: кількість активу (точний десятковий текст), оцінка USD на момент запису, дата й доказ. Оцінки USD рахуються цілими центами, без ринкових API. Невідомі оцінки не вважаються нулями; загальна різниця тоді не показується. Повторні запити не дублюють запис; скасування з причиною зберігає аудит. Інтерфейс порівнює початкову оцінку витрат із відомими записаними витратами, не припускаючи повноту обліку. Це не незалежна on-chain перевірка.

## Оновлення 0.5: резервні копії

У розділі «Резервна копія» кнопка завантажує цілісний SQLite-файл без зупинки сервера. Копія включає всі таблиці, докази, історію та налаштування; не містить тимчасового сесійного токена. Використовується SQLite backup, після чого файл переводиться в автономний journal mode.

Відновлення тільки в новий файл:

```powershell
npm run backup:restore -- "C:\Users\vikto\Downloads\drop-hunter-backup.sqlite" "D:\Projects\ai-drop-hunter\data\restored.sqlite"
```

Замініть ім’я завантаженої копії на фактичне. Інструмент перевіряє цілісність, зв’язки й наявність таблиць. Існуючий файл або службові SQLite-файли за цим ім’ям не перезаписуються.

Щоб відкрити відновлену базу окремо від основної:

```powershell
$env:DROP_HUNTER_DB_PATH = "D:\Projects\ai-drop-hunter\data\restored.sqlite"
$env:PORT = "4318"
npm start
```

Відкрийте http://127.0.0.1:4318. Змінні діють лише в поточному PowerShell; нове вікно термінала використовує стандартну базу й порт. Копія містить усі користувацькі записи та нотатки; зберігайте її окремо від публічного репозиторію.

### Каталог Ink
Джерело «Ink: каталог застосунків» читає публічні дані Mainnet з офіційної сторінки: назви, описи та HTTPS-посилання. Зберігає їх як матеріал дослідження; наявність застосунку не підтверджує винагороду. Якщо формат сайту зміниться, показує помилку й зберігає попередні матеріали. Окремі картки застосунків поки не створюються.
