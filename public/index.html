Найближчі завдання

Робота агентів

Познач проєкти Incrypted, DropsTab або Airdrops.io «Цікавить» або «У роботі». Раз на добу збирач перевіряє картку (для Incrypted також інструкцію), а локальний аналітик готує чернетку при змінах. Працює, поки запущені ПК, сервер застосунку та Ollama.

Твої джерела дослідження

Incrypted · Пріоритетне. Пошук, інструкції, щоденна перевірка обраних.

CryptoRank · Пріоритетне. Тепер підключено через офіційний API (X-Api-Key заголовок) як основний шлях; розширення CryptoRank Reader і ручний імпорт лишаються резервними на випадок, якщо ключ не включає Drophunting-доступ.

DropsTab · Підключено пошук активних карток. Щоденна перевірка обраних карток підключена.

Airdrops.io · Підключено пошук кандидатів. Щоденна перевірка обраних карток підключена.

AirdropAlert · Сайт доступний, але картки не надходять у публічному HTML. Автоматичний збір ще не підключено.

CertiK Skynet · Джерело перевірки безпеки. Автоматичне зіставлення з проєктами ще не підключено; відкрий для ручної перевірки.

Автоматичне отримання джерел

Отримання сторінок і пошук змін. Умови участі перевіряються окремо.

Пошук нових проєктів

Incrypted — основне джерело; DropsTab та Airdrops.io — додаткові. До 40 кандидатів за один пошук. Дублікати пропускаються. Це збір із трекера; ШІ-оцінка прибутковості ще не підключена.

CryptoRank підключено через офіційний API (не через сторінку сайту — та й далі блокує пряме читання, HTTP 403; для неї лишається розширення CryptoRank Reader). Потребує CRYPTORANK_API_KEY у .env; за документацією CryptoRank Drophunting-дані доступні від плану Business — ключ нижчого рівня поверне помилку.

Можливості

Усі мережі на рівних. Наявність проєкту у списку не підтверджує винагороду. Рейтинг — оцінка сигналів, а не ймовірність дропу.
